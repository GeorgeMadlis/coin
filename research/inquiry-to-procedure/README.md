# Inquiry to Procedure

This directory contains the public COIN research trail for *From Inquiry to Procedure - Recorded
Inquiry, Method Evolution, and Operational Method*.

Core current-interpretation files:

- [claims.md](claims.md)
- [critical-overview.md](critical-overview.md)
- [bundle-evolution-analysis.md](bundle-evolution-analysis.md)
- [counterfactual-tests.md](counterfactual-tests.md)

Representation classes:

- [recorded-inquiries/](recorded-inquiries/) preserves proportional,
  source-grounded inquiry trajectories that are useful below formal bundle
  machinery.
- [bundles/](bundles/) preserves formal research bundles used as stronger
  evidence for claims about bundle evolution and method formation.

The two classes are peers. A recorded inquiry is not a simplified bundle, and a
formal bundle should not be weakened to absorb every useful research trail.

Some committed bundle files preserve links that originally pointed to files in private source repositories. When those source files are not copied into COIN, the corresponding path in this directory contains a short omission note instead of reconstructed private content.
