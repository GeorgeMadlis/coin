## Summary

Kolmogorov 1965 and related algorithmic information theory treat complexity in terms of the shortest description that can generate an object. Rissanen 1978 develops minimum description length as a principle for choosing compact explanations. These ideas make compression a precise proxy for understanding. They fit the framework's claim that observers extract summaries rather than copy the whole event stream.

This page is the established mathematical counterpart for compression. It is
not the framework's Wolfram observer-theory foundation. The Wolfram-derived
observer vocabulary, including computational boundedness, equivalencing,
observer persistence, ruliad/rulial-space sampling, and the project's
translation boundary, is documented separately in
[Wolfram observer theory](wolfram-observer-theory.md).

## What it explains

It explains why different short descriptions can compete as summaries of the same material.

## What it fails to explain

It does not by itself model multiple observers, social inquiry, or temporal revision.

## What this framework adds

This framework extends compression theory with a multi-observer setting, a computational-boundedness dimension, and an explicit recording function that separates compressing a record from losing facts before the record exists.

It also keeps two compression vocabularies distinct: AIT/MDL supplies a mature
mathematical literature for description length and model selection, while
Wolfram observer theory supplies the formal analogy of bounded observers
equivalencing complex states into reduced impressions. The project uses both,
but does not treat one as a source for the other.

## Classification

Addresses Type II in the static regime, with relevance to sequential revision.
