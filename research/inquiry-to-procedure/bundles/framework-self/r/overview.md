A v3 framework document exists and is the current design brief. It widens the project from observer disagreement alone to statement evolution, with disagreement treated as the contestation stage. The older v2 document remains historical. The repository workflow has also changed from parallel dual-agent branches to sequential short-lived PR branches.

Steps 0-8 now have interim deliverables, including the Step 8 limitations and falsifiability assessment. This does not validate the framework. The only populated case study is still this self-referential bundle, whose evidence was partly generated by the framework it assesses. The four external case-study bundles remain deferred, Step 9 remains future work, and the framework status remains open and provisional.
