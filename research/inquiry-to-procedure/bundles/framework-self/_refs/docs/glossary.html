This is the repository-level glossary for the statement-evolution framework. It is not, by itself, a promise that every bundle has a separate glossary file. The current bundle layout in docs/framework_v3.md does not reserve a glossary path. Bundle-specific terms should be defined in the relevant PF/S/R/REPRO/INQUIRY concept file unless a later specification creates a dedicated glossary convention. For the pilot bundle, framework-self currently has no separate glossary; its method vocabulary is summarized in bundles/framework-self/s/method.md⚠ unresolved, and the shared framework vocabulary is defined here.

This file now fills the Step 0 glossary stub from the current v3 framework brief and the earlier executed Step 0 draft work. It remains fc-status: open because the framework is still provisional: later Step 1/2/3 work may sharpen the literature counterparts, proof status, or bundle schema.

Scope Commitments

This framework treats statement evolution as a computational-epistemic phenomenon. A statement changes because bounded observers compress an accessible record through limited context windows and frames. The framework does not claim that every disagreement is sincere, neutral, or free of interests; it deliberately brackets motivated reasoning, power, incentives, and identity-protective cognition for Step 8's limitations analysis.

The project makes five commitments:

  1. Analogy, not physics. Wolfram observer theory supplies vocabulary and structure, but the framework does not claim that human or AI disagreement literally is rulial distance. Every Wolfram-derived term must also have a computational definition that stands on its own.
  2. Two-stage access to the past. Present observers do not inspect the event stream E directly. They inspect the surviving record R = r(E), where r is a lossy recording function applied by past observers, instruments, archives, or pipelines.
  3. Two regimes, one machinery. Multi-party disagreement and single-party self-disagreement are modeled with the same machinery. The single-party case is diagonal: later and earlier time slices of one observer trajectory can disagree.
  4. Statement evolution is broader than disagreement. Observer disagreement is the contestation stage of a larger statement trajectory. A statement can also pass through formation, enrichment, critique, and consolidation.
  5. Records prevent future factual irreducibility. The OKF bundle discipline records rounds, supersession, provenance, code, data, and derived artifacts so the trajectory does not later become underdetermined about its own history.

Frontmatter Fields

fc-* fields are custom fact-checking metadata fields used in YAML frontmatter. The prefix keeps project metadata separate from standard OKF keys.

fc-axis

fc-axis says which major bundle lane a concept belongs to. Fact-checking bundles are organized around five axes, not only the PF/S/R trio:

Value Path Meaning
PF pf/ Problem Formulation: what claim, problem, scope, or domain framing is being defined.
S s/ Solution: method, algorithm, assumptions, thresholds, frame, or specification.
R r/ Results: verdicts, outputs, uncertainty, agreement metrics, or result status.
REPRO reproduction/ Reproduction: code, data, environment, checksums, commands, and provenance.
INQUIRY inquiry/ Rounds/history: how the statement changed over time, including moves, stages, types, and supersession.

fc-axis: R is therefore different from formal symbol R = r(E): the former means the Results axis; the latter means the surviving record.

fc-level

fc-level records the disclosure depth of a concept file. Lower values are more compressed; higher values expose more detail.

Value Meaning
0 L0: lay or top-level answer.
1 L1: plain overview.
2 L2: method, result, or formal detail.
3 L3: full context, exact specification, edge cases, or per-item detail.

fc-group

fc-group is not yet a general field in docs/framework_v3.md. In the framework-self pilot bundle it is used locally on s/foundations/* pages to group literature anchors:

Value Meaning in framework-self foundations
A Static regime: disagreement considered as a cross-section at one moment.
B Sequential regime: belief change, inquiry, and argument across time.
C Factual irreducibility: cases where surviving evidence can underdetermine later interpretation because records are missing from R.

For example, factual irreducibility is Group C in the pilot foundations section. This grouping should not be treated as a universal bundle rule unless a later specification promotes fc-group into the shared schema.

fc-round

fc-round answers "when in the ledger?" Its meaning depends on file type:

Location Meaning
Concept file The bundle round in which this version of the concept was established.
inquiry/round-NNNN.md The round file's own bundle-local round number.
Root log.md Repository rounds are recorded as table rows, not usually as fc-round frontmatter.

fc-round is a counter, not a lifecycle classification.

fc-stage

fc-stage answers "what kind of trajectory step was this round?" It is used on inquiry round records and is layered over fc-move.

Value Meaning
formation First creation of the statement on this trajectory.
enrichment Adds information with no live rival position.
critique Questions or probes assumptions without maintaining a rival position.
contestation A live disagreement with a standing counter-position.
consolidation Settlement, convention, verdict revision, supersession, or declared underdetermination.

Short form: fc-round records which numbered step; fc-stage records what lifecycle role that step played.

fc-move

fc-move records the operational move made in an inquiry round. fc-stage is layered over it; the same move can realize different stages depending on whether a standing counter-position exists.

Value Meaning Possible stage(s)
question A request that adds missing context or tests a frame. enrichment, critique
objection A critical challenge to a claim, assumption, method, or frame. critique, contestation
evidence New record content or provenance added to the trajectory. formation, enrichment, contestation
frame-change A change in compression function, category scheme, method, or interpretive frame. contestation, consolidation
convention A jointly adopted rule for treating remaining ambiguity. consolidation
verdict-revision A revised outcome, answer, or status. consolidation

The disambiguator is the live state of the trajectory: an objection that probes assumptions without maintaining a rival claim is critique; an objection that opens or sustains a rival position is contestation.

Formal Symbols

Symbol Definition
E Event stream: the events as they occur, including later claims, objections, evidence submissions, and revisions.
r Recording function: the lossy process by which past observers, instruments, archives, or pipelines compress E into records. It is generally non-invertible.
R = r(E) Surviving record: the accessible trace left after recording. Present observers do not access E directly; they access some part of R.
C_i Context window for observer i: the subset of R considered or available to that observer.
f_i Compression function or frame for observer i: the bounded function that maps accessible record content into an interpretation.
O_i = (C_i, f_i) Present observer i, modeled by a context window and a compression function.
f_i(R intersect C_i) Interpretation emitted by observer i from the accessible surviving record.
f_1(R intersect C_1) != f_2(R intersect C_2) Disagreement between two observers' interpretations.
O(t) = (C(t), f(t)) Observer trajectory: one observer's context and frame as indexed by round/time.
e(t) Evidence or record content added during round t.
C(t+1) = C(t) union e(t) Context update: a round can expand the accessible context window.
f(t+1) = update(f(t)) Frame update: a round can revise the compression function.
p: N -> P Party-assignment function in the sequential multi-observer model. It maps each round number to the acting party in the set of parties P.
stage(t) Stage-classification function assigning round t to formation, enrichment, critique, contestation, or consolidation.

The core chain is E -> r -> R -> f -> interpretation: events are recorded lossily, the surviving record is accessed by a present observer, and that observer's bounded compression function emits an interpretation.

Core Concepts

Term Computational definition Wolfram-source concept / established counterpart Limitation status
Event stream The sequence of events before present interpretation, extended recursively by the inquiry's own rounds. Wolfram state evolution / process history; historiography event record. Not a limitation by itself.
Observer A bounded compressor that maps accessible records through a frame into an interpretation. Wolfram observer; Simon bounded rationality; second-order cybernetics. Resource-relative.
Context window The subset of the surviving record available or attended to by an observer. Observer slice of accessible state; information set or evidence set. Usually resource-relative, unless records are absent from R.
Compression function The frame f that coarse-grains accessible record content into an interpretation. Wolfram coarse-graining; algorithmic information theory compression; model or prior. Resource-relative when translation is hard, not impossible.
Equivalence relation / coarse-graining The grouping induced when f treats different record states as the same for interpretation. Coarse-graining in statistical mechanics; partitions in agreement theory. Resource-relative unless source distinctions are absent from R.
Pocket of reducibility A pattern a bounded observer can compress and use despite a larger irreducible process. Wolfram reducibility inside computational irreducibility. Resource-relative.
Interpretation The output of applying f to R intersect C. Observer-produced reality slice; model output or judgment. Depends on R, C, and f.
Disagreement Non-equality between interpretations from different observers or time slices. Aumann-style disagreement under differing priors/partitions; argumentation conflict. Type-dependent.
Recording function r Lossy compression from event stream E to surviving record R. Extension of observer/compression vocabulary to provenance; W3C PROV / FAIR nearest counterpart. Loss is absolute once information is absent from R.
Surviving record R The record left after r(E), and the only input present observers can access. Archive, dataset, trace, provenance record. Can impose absolute informational limits.
Provenance The recorded chain of custody, generation, versions, checksums, and commands for R or derived results. W3C PROV / FAIR reproducibility. Missing provenance creates factual irreducibility.
Computational irreducibility A process whose result cannot generally be shortcut by a bounded observer even when inputs are present. Wolfram computational irreducibility. Resource-relative.
Factual irreducibility A limit caused by information absent from R, so no observer can recover it by more compute or a new frame. Project extension; Quine-Duhem and historiographic underdetermination as counterparts. Absolute / informational.
Underdetermination Multiple interpretations remain compatible with the surviving record. Quine-Duhem; analytic historiography. Absolute when caused by missing records; otherwise may be resource-relative.
Knowledge bundle A self-contained OKF directory of concept files, reproduction facts, and inquiry records for one problem. OKF bundle; provenance package. A countermeasure, not a limitation.
Coarse-graining family The same content expressed at increasing resolution, from L0 to L3, with deeper levels adding detail. Multi-resolution model; abstraction hierarchy. Lossy by design at shallow levels.
Consistency condition Current shallower levels must not contradict current deeper levels; contradictions are fixed by recorded supersession. Refinement consistency; belief revision. Process rule.
Disclosure level Reader-facing compression depth, L0 through L3. Progressive disclosure; abstraction level. Resource-relative to the reader's need.
Proxy observer A consuming agent that reads only as deep as the user's question requires and answers from that level. Observer as bounded compressor; human-computer interaction progressive disclosure. Resource-relative.
Participating observer An agent or human whose move extends the trajectory and must be logged, classified, and attributed. Dialogue-game participant; second-order observer. Process rule.
Statement trajectory The recorded sequence through which a claim is formed, enriched, critiqued, contested, and consolidated or left open. Wolfram path through state space; Peirce inquiry; belief revision. Dialogically irreducible in general.
Round One trajectory step: claim, move, state update, and possibly revised claim. State-transition step; dialogue move. Process rule.
Move The action taken in a round: question, objection, evidence, frame-change, convention, or verdict-revision. Dialogue-game move; belief-revision operator. Type/stage-dependent.
Stage Lifecycle classification of a round, layered over fc-move: formation, enrichment, critique, contestation, or consolidation. Inquiry-stage vocabulary; argumentation dialogue modes. Process classification.
Formation The first round that emits the statement on a trajectory. Initial state / claim formation. Process classification.
Enrichment Addition of information with no standing counter-position. Evidence accumulation; inquiry expansion. Usually resource-relative.
Critique Critical analysis or probing of assumptions without maintaining a rival position. Critical inquiry; frame testing. Usually resource-relative.
Contestation A live disagreement in which a standing counter-position exists. Argumentation conflict; disagreement regime. Type-dependent.
Consolidation Adoption of a convention, verdict revision, settlement, supersession, or explicit underdetermination. Belief revision closure; convention adoption. Supersedable, not terminal.
Stage trajectory The sequence of round stages across the whole statement trajectory. State-path classification. Process summary.
Type trajectory The sequence of Type I/II/III classifications restricted to contestation-stage rounds. Disagreement trajectory. Type-dependent.
Type I disagreement Different context windows over accessible records. Information-set asymmetry. Data-resolvable in principle; resource-relative in practice.
Type II disagreement Different compression functions or frames over shared records. Prior, partition, model, or frame divergence. Frame-resolvable in principle; resource-relative in practice.
Type III disagreement Disputed content lies outside the surviving record. Historical underdetermination; provenance failure. Absolute / informational.
Self-disagreement / diagonal case Disagreement between a later and earlier time slice of one trajectory, O(t+1) versus O(t). Diachronic belief revision; self-inquiry. Type/stage-dependent.
Type descent Within a truthful, recorded contestation stretch, Type I components tend to resolve before Type II, exposing any Type III residue. Inquiry convergence pattern; provisional P4. Open/provisional; can fail under adversarial moves or frame churn.
Stage ordering / P4' Formation precedes later stages by definition; broader movement toward consolidation is conjectural because consolidation can be superseded. Inquiry lifecycle hypothesis. Open/provisional.
Termination / bottoming-out A contestation reaches a point where further evidence and frame moves no longer change the residual disagreement. Underdetermined closure; stopping criterion. Absolute when the floor is Type III.
Supersession Revision by adding a new version and recording what it replaces, rather than silently editing history. Append-only provenance; belief revision ledger. Process rule.
Sequential multi-observer realization Multiple parties act on one shared round sequence via p: N -> P; each move updates the common trajectory. Interleaved dialogue; shared ledger. Process rule.
Parallel-branch realization Parties advance on independent branches and later reconcile. This is representable but not the repository workflow. Branch/fork workflow. Not the active operational model.
