Repository Structure Audit

Current Shape

The repository has three layers of documentation:

  • docs/framework_v3.md is the current design brief and prompt sequence. It supersedes docs/framework_v2.md, which is retained as historical context.
  • docs/glossary.md now fills the executed Step 0 terminology deliverable at an interim level: scope commitments, formal symbols, fc-* metadata, abbreviations, and core concepts are defined there, while fc-status: open preserves the fact that later steps may sharpen the definitions.
  • docs/related-work.md now fills the executed Step 1 literature-positioning deliverable at an interim level: it maps Wolfram observer theory and adjacent traditions, separates direct source concepts from project translations/extensions, bounds novelty claims, and records stable citations.
  • docs/formal-core.md now fills the executed Step 2 formal-core deliverable at an interim level: it formalizes the static and dynamic models, separates stage and type trajectories, and assigns epistemic status to P1-P5 and P4'.
  • spec/SPEC.md, docs/metrics.md, docs/predictions.md, and docs/limitations.md now fill the executed Step 3, Step 5, Step 6, and Step 8 deliverables at an interim level. docs/paper/README.md remains the planned Step 9 deliverable.
  • bundles/framework-self/ is a populated longitudinal case-study pilot describing this repository. The four external Step 7 case-study directories under bundles/ remain intentional stubs.

Stub Assessment

The remaining stubs should not be filled opportunistically in an unrelated PR. docs/agent-guide.md says a stub must not contain invented content, and the README/step map assigns each deliverable to a specific step PR. The correct lightweight improvement is to point each still-unexecuted stub at the current Step prompt in docs/framework_v3.md and state what source material is available.

docs/glossary.md, docs/related-work.md, docs/formal-core.md, spec/SPEC.md, docs/metrics.md, docs/predictions.md, and docs/limitations.md used to be examples of this pattern, but Steps 0-8 have now been filled from their governing prompts. The pattern still holds for Step 9 and the four deferred external Step 7 bundle stubs.

Correspondence Findings

  • The root README still said "Steps 0-9 not yet executed," which was broadly true for the planned deliverables but ambiguous after framework_v3.md and the framework-self pilot. After Step 0, Step 1, and Step 2 were filled, README status should distinguish the completed glossary, related-work, and formal-core deliverables from remaining stubs.
  • bundles/framework-self/r/overview.md, r/results.md, pf/formal.md, s/method.md, and s/specification.md still described the v2 framing as current after round 4 adopted statement evolution in docs/framework_v3.md.
  • The foundation pages named scholarly anchors with author-year shorthand but no usable reference links. The page for s/foundations/aumann-agreement.md was the most visible case: it referred to Aumann 1976 without a DOI or source link.
  • The bundle layout mostly corresponds to docs/framework_v3.md section 3.2. The only layout mismatch is already intentional and recorded: reproduction/environment.md and r/full-results.md are present in the target layout but absent from the pilot bundle because the pilot has no runnable environment or full result set yet.

Actions Taken

  • Step 0's glossary stub has been filled with scope commitments, terminology, frontmatter metadata meanings, and bundle-glossary policy.
  • Step 1's related-work stub has been filled with literature positioning, stable citations, and bounded novelty assessment; the Wolfram foundation repair now makes Wolfram observer theory the first comparison family and separates it from AIT/MDL.
  • Step 2's formal-core stub has been filled with static and dynamic formalization, proposition statuses, assumptions, and boundary cases.
  • Steps 3-6 have been filled at an interim level: OKF-FC specification, tooling, metrics, and derived predictions.
  • Step 7 has a framework-self-only longitudinal case-study pilot; the four external validation bundle stubs remain deferred.
  • Step 8 has been filled at an interim level: adversarial limitations, stage-taxonomy stress tests, and a falsification registry. Remaining Step stubs point to the current source prompt in docs/framework_v3.md without filling the deliverable.
  • Current self-bundle concept files were superseded where their purpose no longer matched the v3 framing.
  • Foundation anchor pages now include compact reference sections with stable links or DOI links, including a dedicated cross-cutting Wolfram observer-theory foundation page for framework-self.
  • The audit itself is recorded as bundles/framework-self/inquiry/round-0007.md and ledgered in both bundle and repository logs.
