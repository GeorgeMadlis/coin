Derived Predictions

This document fills the Step 6 deliverable. It converts the formal core in formal-core.md and the measurement layer in metrics.md into explicit predictions with null hypotheses, rival explanations, measurement plans, and falsification conditions.

Status note: these are test designs and open hypotheses, not validated results. The framework-self bundle is used below only as a worked coding example and as a one-bundle measurement demonstration. It cannot confirm any population-level prediction.

1. Test Discipline

The predictions use named metrics from docs/metrics.md:

  • Observer-distance metrics: OD-1 predicted-continuation divergence, OD-2 forced-classification disagreement rate, OD-3 description-length asymmetry, OD-4 provenance completeness, OD-5 recoverability of surviving record R, and OD-6 deepest common disclosure level.
  • Contestation-type metrics: TT-1 type descent rate, TT-2 type stalls, TT-3 type reversals, and TT-4 type oscillations.
  • Stage-trajectory metrics: ST-1 stage-transition rate, ST-2 time to first contestation, ST-3 contestation round count, ST-4 time or rounds to consolidation, ST-5 post-consolidation supersession rate, ST-6 re-litigation rate, ST-7 evidence added per round, ST-8 frame-change frequency, and ST-9 observer or agent handoff frequency.

Confirmatory tests require preregistered inclusion criteria, type/stage coding rules, metric definitions, and analysis plans before outcomes are measured. Exploratory tests may refine codebooks, identify failure modes, and generate effect-size estimates, but must not be reported as validation.

The phrase "Type I", "Type II", or "Type III" is never evidence by itself. A prediction is supported only by independently coded records, interventions, and measured outcomes. This matters most for Prediction 6: type descent is part of the framework's vocabulary, so descent cannot be treated as automatic or proven by labeling rounds after the fact.

2. Required Predictions

Prediction 1: Raw Data Helps Type I More Than Type II

field specification
Underlying proposition Type I disagreement is caused by different context windows over accessible records; Type II disagreement persists after relevant records are shared because frames or compression functions differ.
Unit of analysis A dispute component over one stable question Q, measured before and after a raw-data equalization intervention.
Independent variables Diagnosed component type before intervention (I, II, or mixed); presence, depth, and timing of raw-data sharing; OD-4 and OD-5 scores confirming that the shared material was present in R and recoverable.
Dependent variables Change in OD-2; change in verdict agreement; contestation closure or persistence measured by ST-3, ST-4, and TT-2; evidence intensity measured by ST-7.
Expected direction Raw-data sharing should reduce OD-2 and shorten contestation more reliably for Type I components than for Type II components. Type II cases may change only after a frame move, translation, or convention.
Null hypothesis Raw-data sharing has the same effect on Type I and Type II components, or no measurable effect on either after baseline difficulty is controlled.
Rival explanations Type labels may be wrong; the shared data may include an implicit frame; parties may converge from social pressure; the Type I sample may contain easier questions; data equalization may also train parties in a shared codebook.
Inclusion criteria The disputed question is stable; at least two parties or time slices record pre-intervention outputs; raw data or source records are actually shared; pre/post labels use the same codebook; type coding is independent of the measured outcome.
Exclusion criteria No live counter-position; data intervention also changes the decision rule without separate coding; missing pre-intervention labels; strategic or coerced agreement; Type III cases where the required raw data is absent from R.
Required sample For a confirmatory test, at least dozens of independently coded Type I and Type II components, with enough cases per stratum to estimate different pre/post effects. A pilot may use fewer but must report wide uncertainty.
Measurement method Freeze a pre-sharing label set; compute OD-2 before and after sharing; record ST-7 evidence moves; score OD-4 and OD-5; model change in OD-2 by type with case and domain controls.
Possible confounders Question difficulty, party expertise, unequal time spent, label imbalance, codebook quality, hidden frame training, resource limits, and mixed subclaims.
Result that would support it Type I components show a materially larger drop in OD-2 and faster closure after raw-data sharing than Type II components, while Type II cases close mainly when ST-8 frame-change or explicit translation is present.
Result that would weaken it Type I and Type II components improve at similar rates after raw-data sharing, or Type I components remain stalled despite high OD-4 and OD-5 with no residual frame or provenance issue.
Result that would falsify or force reformulation Across well-coded cases, raw-data sharing reliably resolves Type II disagreements without any frame translation, adopted convention, or third frame, and does not preferentially resolve Type I disagreements.
Confirmatory or exploratory Confirmatory when type coding and sharing interventions are preregistered; exploratory for historical cases reconstructed after outcomes are known.

Prediction 2: Persistence Tracks Compression-Scheme Distance

field specification
Underlying proposition After information equalization, persistent disagreement is driven more by distance between compression schemes than by remaining information asymmetry.
Unit of analysis A post-equalization dispute component where parties have access to the same relevant record subset.
Independent variables Compression-scheme distance proxies: OD-3, OD-6, frame-codebook distance, and ST-8; information-asymmetry controls: OD-4, OD-5, and documented context differences.
Dependent variables Persistence duration, measured by ST-3, ST-4, TT-2, and continued OD-2 after equalization.
Expected direction Higher frame or compression distance predicts longer persistence after OD-4 and OD-5 are high and context windows are equalized. Information asymmetry should predict persistence mainly before equalization.
Null hypothesis Persistence is unrelated to compression-scheme distance once information access is controlled, or information asymmetry remains the stronger predictor throughout.
Rival explanations Description length may measure verbosity rather than compression; frame distance may be coded from the disagreement outcome; parties may have hidden information gaps; high-stakes disputes may persist for non-epistemic reasons.
Inclusion criteria Shared record access is documented; frame or codebook features are measured before final outcome; the disputed question remains stable; parties produce comparable outputs.
Exclusion criteria No evidence equalization attempt; provenance gaps that make Type III plausible; unmeasured private evidence; disputes dominated by incentives, identity, or strategic non-cooperation.
Required sample Multiple domains and enough post-equalization cases to separate frame-distance effects from provenance and difficulty, preferably with independent coders for OD-3 and OD-6.
Measurement method Score OD-4 and OD-5; compute or code OD-3 and OD-6; measure persistence with ST-3/ST-4; estimate whether compression proxies predict persistence after information controls.
Possible confounders Domain expertise, task ambiguity, adjudicator frame, language, output format, shared training material, and party power.
Result that would support it Among high-provenance, equalized cases, larger OD-3 or lower OD-6 predicts more contestation rounds and longer time to consolidation.
Result that would weaken it Compression-distance proxies are unstable or fail to predict persistence once domain and case difficulty are included.
Result that would falsify or force reformulation Persistent disagreement is consistently explained by newly discovered information gaps, and frame-distance proxies add no predictive value after repeated equalization in well-recorded cases.
Confirmatory or exploratory Confirmatory only with preregistered frame-distance coding; exploratory when frame distance is inferred from narrative records.

Prediction 3: Frame-Level Convergence Requires Frame Work

field specification
Underlying proposition Type II convergence requires translation between frames, adoption of one frame, or construction of a jointly accepted third frame. More raw data alone is not enough.
Unit of analysis A Type II contestation stretch over one question after relevant data access is equalized.
Independent variables Presence of frame translation, unilateral adoption, or third-frame construction; ST-8 frame-change; OD-6 level of shared description; raw evidence moves measured by ST-7.
Dependent variables Convergence in OD-2, resolution marker in fc-type-at-round, consolidation measured by ST-4, and post-consolidation stability measured by ST-5.
Expected direction Convergence should follow explicit frame work more often than additional data-only moves. Third-frame or translation rounds should raise OD-6 and reduce OD-2.
Null hypothesis Type II convergence is equally likely without frame translation, adoption, or third-frame construction.
Rival explanations The case may have been Type I all along; translation may be recorded after convergence rather than causing it; one party may defer to authority; a hidden adjudication rule may settle the dispute.
Inclusion criteria Type II diagnosis is independently justified; relevant data is shared or recoverable; frame move is timestamped before measured convergence; outputs are comparable.
Exclusion criteria Type III underdetermination; raw-data intervention and frame adoption occur in the same unseparated round; no live counter-position; coerced or administrative closure without interpretive convergence.
Required sample Type II contestation stretches with enough frame-work and no-frame-work cases to compare closure rates, ideally across several domains.
Measurement method Code rounds for translation, adoption, or third-frame construction; compute OD-2 and OD-6 before and after; compare ST-4 and ST-5 outcomes to data-only stretches.
Possible confounders Authority gradients, settlement incentives, vague consolidation criteria, mixed Type I/II components, and retrospective frame coding.
Result that would support it Type II cases converge mainly after recorded frame work, while data-only rounds increase ST-7 without comparable drops in OD-2.
Result that would weaken it Many Type II cases converge during data-only rounds, but inspection shows unrecorded or implicit frame work may have occurred.
Result that would falsify or force reformulation Independently confirmed Type II cases routinely converge from additional raw data alone, with no detectable translation, adoption, third frame, authority closure, or type miscoding.
Confirmatory or exploratory Confirmatory when frame-work categories and convergence metrics are specified in advance; exploratory when applied to historical narratives.

Prediction 4: Irreproducibility Splits Into Cost-Limited And Provenance-Limited Populations

field specification
Underlying proposition Some irreproducible claims are computationally blocked but fully specified, while others are factually blocked because provenance or inputs are absent. These populations should respond differently to added resources.
Unit of analysis A scientific or computational claim with a recorded reproduction attempt.
Independent variables Irreproducibility class: cost-limited/computational versus provenance-limited/factual or mixed; OD-4; OD-5; added resources such as compute, time, access, or expertise.
Dependent variables Reproduction success, recoverability level OD-5, convergence in OD-2, closure time ST-4, and residual underdetermination status.
Expected direction Cost-limited cases improve with resources when code, data, and environment are pinned. Provenance-limited cases remain underdetermined until missing records or recorder specifications are recovered, not merely until more compute is spent.
Null hypothesis Added resources have the same effect on cost-limited and provenance-limited irreproducible claims.
Rival explanations Reproduction teams differ in skill; cost estimates may be wrong; provenance gaps may be irrelevant; proprietary access may look like provenance loss but be reversible with permissions.
Inclusion criteria Claim has a clear target output; reproduction attempt records code/data/environment/provenance; blockers are classified before resource escalation; outcomes are timestamped.
Exclusion criteria No definite reproduction target; unpinned sources; legal or ethical barriers that prevent any test; claims where failure means the original claim is false rather than irreproducible.
Required sample A stratified set of irreproducible claims across computational and empirical domains, with repeated resource escalation or documented attempts. Step 7's climate reproduction pilot can supply only an initial case.
Measurement method Score OD-4 and OD-5; classify blockers as computational, factual, mixed, or unknown; add resources in documented increments; measure changes in reproduction status and disagreement.
Possible confounders Software decay, hardware nondeterminism, ambiguous target metrics, data licensing, undocumented preprocessing, and changing scientific standards.
Result that would support it Computational blockers move from OD-5 level 2 or 3 toward level 4 under resources, while factual blockers remain unresolved without provenance recovery.
Result that would weaken it The two populations cannot be reliably distinguished, or many provenance-limited cases resolve with compute alone because the missing fields were not actually needed.
Result that would falsify or force reformulation Provenance-limited cases resolve at the same rate as cost-limited cases under resource increases without any new provenance, or fully specified cost-limited cases fail to improve despite adequate resources.
Confirmatory or exploratory Exploratory until blocker classification is reliable; confirmatory after preregistered reproduction protocols exist.

Prediction 5: Thin Records Make Disagreement More Persistent And Frame-Dependent

field specification
Underlying proposition Thinly recorded events leave more content outside R, making disputes more persistent and more dependent on observers' frames.
Unit of analysis A dispute over an event or claim with a scored surviving record.
Independent variables Record thickness: OD-4, OD-5, number and depth of disclosure levels, source density, and missing recorder-specification fields.
Dependent variables Persistence by ST-3/ST-4; frame dependence by OD-3, OD-6, ST-8, post-equalization OD-2, and Type III classifications.
Expected direction Lower OD-4/OD-5 predicts more persistent disagreement, lower deepest common disclosure level, more frame-change rounds, and more Type III or underdetermined closures.
Null hypothesis Record thickness is unrelated to persistence or frame dependence.
Rival explanations Thin records may concern simpler low-stakes events; well-recorded events may be more complex; later documentation may be produced because a dispute was already persistent.
Inclusion criteria A defined target claim; a pre-outcome provenance checklist; comparable cases or matched controls; recorded disagreement outcomes.
Exclusion criteria Events with no live dispute; cases where records are intentionally inaccessible but not absent; disputes dominated by normative preferences rather than claims about the event stream.
Required sample Matched thin-record and thick-record disputes across similar domains, or within-domain cases with varying provenance completeness.
Measurement method Score OD-4/OD-5; code missing recorder fields; measure persistence and frame dependence; compare matched cases or model outcomes with domain controls.
Possible confounders Event complexity, public salience, incentives to litigate, record quality rather than quantity, archival bias, and retrospective documentation.
Result that would support it Thin records show longer contestation, lower OD-6, more ST-8 frame moves, and more underdetermined outcomes than matched thick records.
Result that would weaken it Record thickness predicts persistence only before domain complexity controls, or provenance checklists are too coarse to detect relevant missingness.
Result that would falsify or force reformulation Well-matched thin and thick records show no persistence or frame-dependence difference, and thin records do not produce more Type III or underdetermined residues.
Confirmatory or exploratory Confirmatory with preregistered record-thickness scoring and matched cases; exploratory for archival case studies.

Prediction 6: Contestation Stretches Tend Toward Type I -> Type II -> Type III Descent

field specification
Underlying proposition Under truthful moves, adequate recording, stable claim scope, and fair opportunity to add evidence and frames, contestation tends to resolve accessible context gaps before frame gaps, and frame gaps before irrecoverable record residues.
Unit of analysis A contestation stretch: adjacent contestation-stage rounds over one stable question, possibly separated by non-contestation rounds only if the live counter-position remains continuous.
Independent variables Round position in the contestation stretch; type depth; truthfulness and recording-discipline indicators; classification assumptions; evidence and frame moves (ST-7, ST-8).
Dependent variables TT-1 type descent rate, TT-2 stalls, TT-3 reversals, TT-4 oscillations, and eventual fc-status closure.
Expected direction The modal resolution order is Type I before Type II before Type III. Violations should predict untruthful moves, strategic behavior, mixed claims, unstable coding, or misclassification.
Null hypothesis Type transitions in recorded contestation stretches show no downward/deeper ordering, or reversals and oscillations are as common as descent after coding and claim-scope controls.
Rival explanations Coders may impose the framework vocabulary after the fact; mixed subclaims may mimic descent; early Type I labels may be easier to see; records may omit adversarial moves; later Type III labels may reflect fatigue.
Inclusion criteria At least two contestation rounds; stable question or decomposed subclaims; independent type rationales; recorded evidence/frame moves; truthfulness and classification assumptions stated before testing descent.
Exclusion criteria Single contestation round; no live counter-position; knowingly adversarial or satirical records unless testing boundary failure; unresolved mixed claims that cannot be decomposed; type labels added only from the expected sequence.
Required sample Multiple contestation stretches with at least two type-coded contestation rounds each. A confirmatory test needs enough transitions to estimate descent, stall, reversal, and oscillation rates with uncertainty.
Measurement method Independently code type per contestation round from evidence, not from sequence order; compute TT-1 through TT-4; audit violations for truthfulness, recording, and classification assumptions; compare to a random or no-order baseline.
Possible confounders Post-hoc coding, uneven round granularity, mixed claims, intervention timing, party incentives, label drift, hidden off-record negotiation, and selective publication of orderly cases.
Result that would support it Positive TT-1 is common in truthful, well-recorded, single-claim stretches, and deviations are explained by preregistered boundary conditions or miscoding.
Result that would weaken it Descent appears only when coders know the expected order, or many well-recorded stretches stall or reverse without clear boundary-condition explanations.
Result that would falsify or force reformulation Well-recorded, truthful, non-adversarial, independently coded contestation stretches regularly resolve Type II before Type I, return from Type III to Type I without new records, or oscillate in ways not attributable to mixed claims or misclassification.
Confirmatory or exploratory Confirmatory only with independent per-round coding blinded to sequence where possible; exploratory for existing bundles whose types were coded retrospectively.

Prediction 7: Documented Single-Party Trajectories Re-Litigate Less

field specification
Underlying proposition Bundle discipline preserves what was settled, why it was settled, and what superseded it, so a single party should reopen settled points less often than in comparable undocumented inquiries.
Unit of analysis A single-party inquiry trajectory of comparable depth, task type, and duration.
Independent variables Documentation regime: full OKF-FC bundle, lightweight ledger, ordinary notes/chat/git history, or undocumented memory-based inquiry; OD-5 recoverability of the trajectory record.
Dependent variables ST-6 re-litigation rate; repeated contestation over settled issues; time lost to reconstructing prior reasoning; post-consolidation supersession with and without new evidence (ST-5).
Expected direction Full bundle discipline should produce lower ST-6 than undocumented or weakly documented inquiries of comparable depth. Supersessions may still occur, but should cite new evidence, frame rationale, or explicit correction rather than merely replay old grounds.
Null hypothesis Documentation regime has no relationship to re-litigation after trajectory depth and task difficulty are controlled.
Rival explanations More disciplined users may re-litigate less regardless of bundles; documented inquiries may be more complex; undocumented inquiries may abandon disputes rather than re-litigate; issue-id coding may favor bundles.
Inclusion criteria Single-party or diagonal trajectory; stable issue identifiers or reconstructable issue map; comparable task depth; post-consolidation period observable.
Exclusion criteria Multi-party disputes where social dynamics dominate; no consolidation events; no way to identify repeated issues; deliberate red-team repetitions.
Required sample Matched documented and undocumented single-party trajectories, ideally from the same person or team across similar task types, with independent issue coding.
Measurement method Assign issue ids; identify consolidation rounds; code later reopenings with or without new evidence/frame rationale; compute ST-6 and ST-5; compare by documentation regime with task controls.
Possible confounders User discipline, task complexity, external interruptions, memory aids outside the bundle, issue granularity, and selective retention of documented cases.
Result that would support it Full-profile bundles have lower ST-6 than comparable undocumented chains, while later supersessions mostly cite new evidence, corrected provenance, or explicit frame changes.
Result that would weaken it Re-litigation is low in both documented and undocumented chains, or bundle issue coding is too subjective to compare.
Result that would falsify or force reformulation Bundle-disciplined single-party trajectories show equal or higher same-ground re-litigation than comparable undocumented inquiries, despite stable issue ids and comparable task complexity.
Confirmatory or exploratory Exploratory until stable issue-id coding is demonstrated; confirmatory after matched samples and re-litigation criteria are preregistered.

Prediction 8: Critique Before First Contestation Predicts Shorter, More Stable Trajectories

field specification
Underlying proposition A critique stage before first contestation exposes frame weaknesses early, so later contestation should require fewer rounds, reach consolidation faster, and be superseded less often afterward. This tests the conjectural P4'(b) subclaim, not the definitional P4'(a).
Unit of analysis A statement trajectory with a formation round and either a first contestation round or right-censored no-contestation status.
Independent variables Binary pre-contestation critique indicator: whether at least one fc-stage: critique round occurs after formation and before first contestation; number and depth of critique rounds; retrospective versus original stage classification.
Dependent variables ST-3 contestation round count before next consolidation, ST-4 rounds/time from first contestation to consolidation, and ST-5 post-consolidation supersession rate. Secondary: ST-6 re-litigation.
Expected direction Trajectories with critique before first contestation should have fewer contestation rounds, faster consolidation, and lower post-consolidation supersession than trajectories entering contestation directly from formation or enrichment.
Null hypothesis Pre-contestation critique has no relationship to contestation length, consolidation time, or post-consolidation supersession after task complexity and documentation quality are controlled.
Rival explanations Easier cases may permit critique before contestation; retrospective stage classification may create a false pattern; critique quality matters more than presence; early critique may delay first contestation without improving later stability.
Inclusion criteria Formation round identified; stage sequence available; first contestation identified or explicitly unobserved; consolidation and supersession rules stable; post-consolidation observation window recorded.
Exclusion criteria No stage records; stage labels assigned only after knowing outcomes without uncertainty marks; trajectories with no possible contestation opportunity; consolidation absent unless handled as censored in the analysis.
Required sample Multiple statement trajectories in both groups, with enough post-consolidation follow-up to estimate supersession. The framework-self bundle alone has one trajectory and belongs only to the no-pre-critique group.
Measurement method For each trajectory, compute precrit = any(stage(t) == critique for formation < t < first_contestation). If no contestation occurs, record as censored or analyze separately. Then compute contestation rounds before next consolidation, rounds/time to consolidation, and post-consolidation supersession share. Record whether stages were original frontmatter or retrospective classifications.
Possible confounders Retrospective coding, small samples, varying statement scope, task difficulty, party handoffs (ST-9), documentation maturity, and different follow-up windows after consolidation.
Result that would support it Across comparable trajectories, the pre-critique group has lower ST-3, lower ST-4, and lower ST-5, with the effect persisting after controls and sensitivity checks excluding retrospective labels.
Result that would weaken it The association appears only in retrospectively classified stages, disappears after task controls, or lowers contestation rounds while increasing post-consolidation supersession.
Result that would falsify or force reformulation Preregistered, well-recorded trajectories with pre-contestation critique consistently show equal or longer contestation stretches and equal or higher post-consolidation supersession than direct-entry trajectories.
Confirmatory or exploratory Exploratory for framework-self; confirmatory only in a multi-trajectory sample with preregistered stage coding and a small-sample/censoring plan.

3.3 Prediction 8 Calculation Design

For each statement trajectory b:

  1. Let F_b be the formation round.
  2. Let C_b be the first contestation round after formation. If no contestation occurs, mark the trajectory NO_CONTESTATION and analyze it separately or as right-censored.
  3. Compute precrit_b = 1 if any round t satisfies F_b < t < C_b and stage(t) = critique; otherwise 0.
  4. Let G_b be the first consolidation round after C_b. If none exists, mark ST-4 = NOT_OBSERVED and treat the trajectory as censored.
  5. Compute contestation_count_b as the number of contestation rounds from C_b through the round before G_b.
  6. Compute rounds_to_consolidation_b = G_b - C_b, plus calendar time when timestamps are available.
  7. Compute post_consolidation_supersession_rate_b as the share of observed rounds after G_b that supersede a current concept, with a sensitivity check using concept counts rather than round counts.
  8. Record whether each stage label was original frontmatter or retrospective classification. Run sensitivity checks excluding trajectories whose grouping depends on retrospective labels.

The small sample is not a nuisance detail; it is the core limitation. With one trajectory, any numeric result is a worked calculation, not an estimate of a population relationship.

4. Reporting Rules For Later Work

Later case studies and working-paper sections should report these predictions with four separations intact:

  1. Metric availability is not a result. NOT MEASURABLE values are evidence about the record, not evidence for or against a proposition.
  2. Exploratory observations may motivate a refined codebook, but cannot be described as confirmation.
  3. Retrospective stage and type classifications must be marked and sensitivity checked.
  4. A falsifying result should reformulate the proposition or boundary conditions, not be absorbed by relabeling a case after the fact.
