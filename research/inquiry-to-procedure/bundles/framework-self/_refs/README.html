observer-disagreement-framework

This repository is a research scaffold and pilot for statement evolution: a computational framework for how a statement is enriched, critiqued, contested, and consolidated over recorded rounds, plus per-problem fact-checking bundles in the Open Knowledge Format (OKF v0.1). Observer disagreement — multi-party or diagonal/self — is the central contested regime the framework covers, but not the only stage a statement passes through; see docs/framework_v3.md (current) for the full stage vocabulary, superseding docs/framework_v2.md (retained, historical). The repository name reflects the project's original, narrower scope and is kept as-is for link stability. The project now contains interim framework deliverables through limitations/falsifiability, tooling, derived predictions, and one self-referential longitudinal case-study pilot; it does not yet contain the four deferred external case-study validations or population-level empirical results.

The committed HEAD of main is the canonical current state of every bundle in bundles/; rendered HTML, exported zips, and catalogs are derived, commit-pinned artifacts (see docs/framework_v3.md §3.7).

Workflow

Work is sequential and single-agent: one change request is one PR from a short-lived work/<slug> branch, opened by whichever agent (Claude Code, Codex, or another) is invoked, merged to main, then deleted. Agents may still weigh in on the same material one after another — each acting as a distinct observer whose disagreement is recorded as inquiry rounds and ledger lines, not as parallel branches. The committed HEAD of main is the canonical current state of every bundle. See docs/agent-guide.md for the full working rules and ledger discipline.
