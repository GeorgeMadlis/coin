Framework Self-Description Bundle

This bundle describes the observer-disagreement-framework project itself, in layers of increasing detail. Start at the level that matches your question, then descend only when you need more resolution.

Level map

  • answer.md - L0: a compact layman's answer describing what the project is.
  • PF: problem - What problem the framework tries to solve.
  • S: framework - What model, method, and literature anchors it uses.
  • R: status - What exists now and what remains open.
  • Reproduction - How this bundle can be re-derived from its source documents.
  • Inquiry - How this bundle evolved and how future rounds should be recorded.
