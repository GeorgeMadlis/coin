Move

Step 1 literature positioning is repaired after identifying an incomplete treatment of Wolfram observer theory. The repository previously used Wolfram observer theory as a foundation but did not give the framework-self bundle a dedicated Wolfram foundation concept, and docs/framework_v3.md relied on a single interview transcript for Wolfram-derived claims.

Evidence added

  • docs/related-work.md now places Wolfram observer theory first and separates direct Wolfram concepts, this project's formal translations, and this project's extensions.
  • docs/framework_v3.md now cites primary Wolfram sources and independent ruliology/observer-theory commentary, while retaining the formal-analogy limitation.
  • s/foundations/wolfram-observer-theory.md is added as the bundle's cross-cutting Wolfram foundation concept.
  • s/foundations/ait-compression.md now states that AIT/MDL is the established mathematical counterpart for compression and should not be conflated with Wolfram observer theory.
  • s/foundations/index.md, s/overview.md, and s/method.md now link to the dedicated Wolfram foundation page.

Effect on state

Context window: added primary Wolfram sources, independent arXiv commentary, and a source map for direct concepts versus translations/extensions.

Frame: unchanged at the framework level. This remains a statement-evolution framework using Wolfram observer theory as formal analogy. The round narrows attribution risk by making the source boundary explicit.

Resulting revisions

  • s/foundations/wolfram-observer-theory.md is created at round 18.
  • s/foundations/ait-compression.md supersedes s/foundations/ait-compression.md@r13 to add the Wolfram/AIT distinction and cross-reference.
  • s/overview.md supersedes s/overview.md@r4 to link the one-paragraph method summary to the dedicated Wolfram foundation.
  • s/method.md supersedes s/method.md@r16 to add the source-boundary method step.
  • s/foundations/index.md, inquiry/index.md, bundle log.md, and root log.md are updated without supersession frontmatter because they are reserved navigation/ledger files.

Classification rationale

It adds source coverage, bibliographic context, and conceptual navigation for the existing framework without maintaining a rival position and without declaring the framework settled. Because the round is not contestation-stage, fc-type-at-round is intentionally omitted.
