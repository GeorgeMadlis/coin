Portable local bundle guide

Fazenda Sucuri evidence package

This page explains reproduction/fazenda_sucuri_screening_aoi_contact_sheet.pdf and provides direct relative links to the bundle's HTML and JSON artifacts. It is designed to be opened directly from the unzipped bundle root without a local web server.

No sandbox URLs No iframe or PDF embedding No fetch/XMLHttpRequest No external libraries
Why this version avoids permission prompts Browsers may restrict an HTML page from automatically reading neighboring local files. This guide does not attempt to read them. Every artifact opens only after you click a normal relative link. The search and copy-path controls operate solely on text already present in this page.

What the contact sheet represents

The contact sheet is a derived visual index. It compresses the canonical 12-page PDF into a single page for rapid inspection; it is not the source of the report's metrics or conclusions. Use the canonical HTML and JSON files above for detailed inspection.

1Cover and AOI

Report identity, commodity, geography, date, and overview imagery.

Metadata

Page metadata JSON | Published bundle manifest | Local metadata manifest

2Executive summary

High-level evidence status, headline metrics, and review boundary.

3Assessment workflow

Baseline, change, commodity, and intersection logic used by the screening report.

4Regional context

AOI placement in Minas Gerais and surrounding land context.

52020 forest baseline

JRC GFC2020 baseline evidence and mapped forest area.

6Post-2020 loss

Hansen loss evidence, coffee overlap, and intersection metrics.

7Satellite evidence

Corrected before/after Sentinel-2 panels and AOI boundary.

8Interpretation

Evidence detected, gaps, review needs, and legal-outcome boundary.

9Data and methods

Datasets, processing method, spatial resolution, and temporal scope.

10Audit trail

Run metadata, cutoff, end year, CRS, software, and integrity references.

11Deterministic artifacts

Lists report.json, report.html, report.pdf, metrics.csv, manifest, and evidence images.

12Appendix

References, limitations, evidence gaps, schema, and methodology version.

Browser behavior
The page itself does not request broad folder access. Clicking an artifact link asks the browser to open that specific neighboring file. A browser may display JSON as plain text or download it, depending on browser settings. Both behaviors preserve access to the file without a local server.
