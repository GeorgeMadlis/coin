# Agent contract

## Proxy observer

When answering about this bundle, read the shallowest page that answers the question and cite the
path used. Use `answer.md` for the current state, `s/task-scope.md` for scope questions,
`reproduction/lineage.md` for historical Liberia/wood lineage, and `reproduction/source-evidence.json`
for counterpart/handoff pins.

This role observes a recorded bundle state made from source records, process descriptions,
observation artifacts, handoff metadata and hashes. It is not the Hansen/TMF/RADD/Sentinel/Forest
Atlas process itself, and a raster, vector polygon or scene image is an observation artifact or input
unless a documented procedure turns it into a finding.

## Participating observer

When changing this bundle, append a new round under `inquiry/` and update this bundle's `log.md` and
`inquiry/index.md`. Use the scope-change protocol in `s/task-scope.md` before writing. Do not edit,
move, renumber, or rewrite legacy `eudr-gee` rounds 30-31.

Before writing a same-bundle round, perform the live Frame Declaration check: classify the proposed
move as same-frame evidence evolution, task-boundary change, method-family/rule change, ordinary
presentation history or unresolved. Only same-frame evidence evolution belongs directly here.

## Evidence discipline

Do not copy counterpart evidence artifacts into this source bundle. Reference counterpart commits,
paths and checksums. A missing public source is an evidence gap, not a zero-valued layer. A concession
boundary is not a production plot unless later pinned evidence resolves that role.
