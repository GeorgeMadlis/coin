# eudr-wood-liberia-fmc-area-k

Task-specific OKF-GSP bundle for EUDR wood/timber evidence collection and screening in Liberia,
beginning with Forest Management Contract Area K.

This bundle is a child of `bundles/eudr-gee`. It records the Liberia/FMC Area K task frame. It does
not redefine the method-family rules, and it does not treat the concession boundary as a production
plot.

## Current State

- Purpose: EUDR evidence collection and screening.
- Commodity: wood/timber.
- AOI/context: FMC Area K, Liberia.
- Current AOI role: forest concession / screening AOI / legal-provenance context.
- Production-plot status: unresolved.
- Source-linkage status: missing public harvesting-block, tree/log and chain-of-custody evidence.
- Current evidence state: `human_review_required` / `pinned-not-reproduced`.
- Current report package: `area-k-real-005`.
- Current report integration: page 5 maps JRC forest 2020; page 6 maps Hansen/JRC, TMF and RADD
  comparison evidence; page 7 maps Sentinel-2 visual context.
- Legal boundary: no automatic compliance or non-compliance determination; no production plot,
  harvesting block, shipment, tree/log or chain-of-custody linkage is established.
